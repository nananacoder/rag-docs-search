   (allowlist-gated on this project — probed). Truncated outputs are NOT
   normalized (measured norm 0.587); pipeline L2-normalizes.

   by chapter ranges (golden/README C-rules). A future re-ingest via
   pipeline CLI recreates a single book_id — the part split currently

   make re-ingestion nearly free. Cache keys include model names.

   stopped cost ~$0.05/day. Total project spend to date: ~$10.
